# DX DEV | Fullstack Developer

Personal portfolio and contact hub for **DX DEV** ([dixxxie.com](https://dixxxie.com)).

## Tech Stack

- React 19 + TypeScript
- Three.js
- Tailwind CSS v4
- Vite

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
